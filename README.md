# Problem-Solving-Pattern

| #  | Approach                     | Main idea                                       |
| -- | ---------------------------- | ----------------------------------------------- |
| 1  | **Brute Force**              | Try all possible solutions                      |
| 2  | **Recursion**                | Break problem into smaller versions of itself   |
| 3  | **Backtracking**             | Try → explore → undo → try another              |
| 4  | **Divide & Conquer**         | Divide into smaller independent problems        |
| 5  | **Greedy**                   | Make the best choice at each step               |
| 6  | **Dynamic Programming (DP)** | Store/reuse results of overlapping subproblems  |
| 7  | **Binary Search**            | Repeatedly reduce search space by half          |
| 8  | **Two Pointers**             | Use two indexes to process data efficiently     |
| 9  | **Sliding Window**           | Maintain a moving range/window                  |
| 10 | **Hashing**                  | Use hash map/set for fast lookup                |
| 11 | **Bit Manipulation**         | Solve using binary/bit operations               |
| 12 | **Graph Algorithms**         | BFS, DFS, Dijkstra, MST, Topological Sort, etc. |
